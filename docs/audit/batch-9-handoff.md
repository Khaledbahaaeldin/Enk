## 1. What exists

### Task 24: home-screen widget (Glance 1.1.1)
- `EnkWidget` (responsive sizes 100 x 100 dp and 250 x 100 dp; wide from 250 dp). Three layouts: empty-state paper card ("Nothing yet" / "Tap to write your first note."), small graphite card (miniature rail and carriage, two lines of the note, a 48 dp "+ New" pill), wide paper card (meta line, two lines of the note, a 48 dp "+ New note" pill). Colours are fixed paper and graphite values (the widget is not themed); the text uses the system monospace because Glance cannot load Courier Prime.
- Actions: `app.enk.action.NEW_NOTE` and `app.enk.action.OPEN_NOTE` (+ `app.enk.extra.NOTE_ID`) start `MainActivity` (`launchMode="singleTask"`). `WidgetIntentParser.consume(intent)` parses and marks the intent `app.enk.extra.HANDLED`; `MainActivity` calls it in `onCreate` (when not restored) and `onNewIntent`. A new tap is a new `Intent`, so it is acted on; the same intent object replayed is not. `MainViewModel.handleWidgetAction` waits for the start-up load, then creates a note (NEW_NOTE) or opens it if it exists and is not trashed, otherwise the most recent note (OPEN_NOTE). Unknown actions, blank, 10,000-character and wrong-type ids do nothing.
- Refresh: `EnkWidgetManager.requestUpdate` through `UpdateGate(clock, minIntervalMs = 5000)` (coalescing, trailing refresh, clock going backwards), called after an autosave (`WriterViewModel.onPostSave`), trash and restore (`BoxViewModel.onWidgetUpdate`), a finished import (`SettingsViewModel.onNotesChanged`) and `MainActivity.onStop`. `updateAll` runs on `Dispatchers.IO`; failures are swallowed.
- The widget reads through one process-wide container (`WidgetContainer`), not one per refresh.
- Privacy property: the widget shows the text of the most recent note on the home screen. Nothing else is done about it; the author decides later whether to add a setting.
- No network: `ACCESS_NETWORK_STATE` pulled in by Glance is removed in the manifest; `scripts/check-no-network.sh` passes on the merged manifest.

### Task 25: Credits and licenses
- Setup > About > "Credits and licenses" (chevron row) opens `Route.Credits` (`Dest.Setup` selected; back goes to Setup). Groups in order: App license, Fonts, Sounds, Libraries.
- App license opens the full Apache 2.0 text (asset `licenses/Apache-2.0.txt`, copied from `LICENSE` by `generateCredits`) in a scrolling dialog; Courier Prime and Inter open their OFL text, which starts with the copyright line, from the existing assets. Sounds are grouped per author, source and licence ("Classic: keys, space, backspace; ..."), not per file. Libraries list name, version, licence and a link (`ACTION_VIEW`; `ActivityNotFoundException` shows a message).
- `generateCredits` writes `credits.json`, `libraries.csv` and `Apache-2.0.txt` into the assets from `docs/provenance.csv`, `docs/libraries.csv` and `LICENSE`; `checkCredits` (wired into `check`) fails when any of them is stale. `CreditsLoaderTest` reads the real files and compares `docs/libraries.csv` with the runtime dependencies in the version catalog and the build files.

### Task 26: accessibility, reduced motion, contrast
- One `reduceMotion(context, settings)` (+ a pure overload) used by `MotionPolicy` and `rememberReduceMotion`.
- `textMuted` raised from `#8B8578` to `#948F83` (4.99:1 on `chassisBottom`, 4.75:1 on `panelBottom`); DS 2.1 and `TokensTest` updated; goldens unchanged.
- Carriage: description "Writing marker. Drag to scrub, long press to toggle lamp", state "Lamp on"/"Lamp off", a 48 dp touch area, and a "Toggle lamp" custom action for TalkBack. Wordmark: button "Open the Box". Note cards: custom actions "Open note actions", "Move to divider", "Move to trash".
- Landscape with the keyboard up: windows shorter than 360 dp use a compact layout. The top bar is 40 dp and the paper starts at 44 dp; the font shrinks only as far as needed so the caret line fits above a rail that leaves the carriage inside the window (8 sp floor); the paper's top fade is 8 dp; the lamp panel overlays instead of pushing the rail up; the hint is hidden. Without the keyboard (336 dp) the font stays 22 sp. Windows of 360 dp and taller are unchanged. The text does reflow smaller when the keyboard opens in landscape.

## 2. How a user reaches every new thing
- Widget "+ New" / "+ New note": launcher > `MainActivity` (NEW_NOTE) > the writer on a new note. Widget note text: OPEN_NOTE > the writer on that note. Empty-state card: NEW_NOTE. Back from there follows the existing `routeBack` (Note > Box).
- Credits: Write > Setup (nav bar) > scroll to About > "Credits and licenses"; back returns to Setup. License dialogs: tap a row; Close or back dismisses.
- Compact writer: rotate to landscape and open the keyboard.
- TalkBack lamp: focus the carriage, actions menu, "Toggle lamp".

## 7. What the audit found and what was done about it
1. **Landscape writer with the keyboard up** was not fixed (the paper stayed about 40 dp; only the hint was hidden). Fixed with the compact geometry above; `WriterCompactLayoutTest` (3 tests).
2. **Sounds credits listed about 35 file paths.** Now one row per author, source and licence (`groupSoundCredits`, tested on the real data and on odd paths).
3. **Licence texts were not shown** and the Courier Prime copyright line in code (2013, Quote-Unquote Apps) disagreed with the asset (2015, The Courier Prime Project Authors). The dialogs now read the assets; the unused `AppLicenseInfo` strings were deleted.
4. **Widget tap dedupe was dead code** (no `TAP_ID` was ever sent). Removed; replaced by the `HANDLED` marker described in section 1, tested in `WidgetIntentParserTest` and `WidgetEntryPointTest`.
5. **A Room database per widget refresh**: `WidgetContainer` is one per process (`WidgetEntryPointTest`).
6. **Tests that could not fail**: the "paper exposes text" test used a plain `BasicTextField`; replaced by `WriterAccessibilityTest`, which drives the real `WriterScreen`. Added the libraries-versus-catalog test, font-scale 1.3 and 2.0 layout tests for Box, Find, Trash, Setup and Credits (`LargeTextLayoutTest`: title below the status bar, content below the title, nothing off the sides, every tappable thing 48 dp measured with `touchBoundsInRoot`), wordmark, lamp action and note-card action tests. A widget action can no longer race the start-up load.
7. **TalkBack could not toggle the lamp**: "Toggle lamp" custom action on the carriage.
8. **Import now refreshes the widget** (`SettingsViewModel.onNotesChanged`).
9. **Unused imports in `PaperText.kt`** reverted to the file on `main`.
10. **Handoff** regenerated by script.

Tests broken on purpose and watched fail, then restored: the "Toggle lamp" action made a no-op (`WriterAccessibilityTest` failed); the compact geometry switched off (`WriterCompactLayoutTest` geometry test failed); the hint-hiding condition switched off (`WriterCompactLayoutTest` hint test failed). `checkCredits` was shown to fail by changing a row of `docs/provenance.csv` (`credits.json is out of date with docs/provenance.csv`) and the row was restored.

## 8. Deviations and decisions
- Widget sizes are 100 x 100 and 250 x 100 dp breakpoints (the cell sizes a launcher actually reports), not 170 x 170 and 360 x 160 dp; text is the system monospace (Glance cannot load Courier Prime); colours are fixed.
- `AccessibilityTest`, `WriterAccessibilityTest`, `LargeTextLayoutTest` and `WriterCompactLayoutTest` use the compose rule and are on the `testReleaseUnitTest` exclude list in `app/build.gradle.kts` (`ui-test-manifest` is debug-only).
- The plan's `androidTest` accessibility tests are Robolectric tests in `app/src/test` and `design/src/test`.
- `ActivityScenario` on `MainActivity` hung the suite under Robolectric, so the activity's decision is the pure `WidgetIntentParser.consume`, tested directly; the activity's two call sites are one line each.
- On a first launch with an empty database the start-up creates a first note and a widget NEW_NOTE creates a second, so one empty "Untitled" note remains. Not changed.
- Widget strings and the credits strings are literals, like the rest of the app.

## 9. Gaps, stated plainly
- No launcher was available: the widget layouts, the 48 dp pills, resizing, wallpapers and TalkBack are untested on a device (`docs/qa/widget-device-checklist.md`).
- TalkBack, the system font scale, "remove animations" and the real keyboard in landscape on a phone were not run (`docs/qa/a11y-device-checklist.md`).
- The compact landscape layout was seen on the emulator only (keyboard about half the screen); not on a phone.
- The widget picker shows no preview image.
- `libraries.csv` lists the Compose BOM version for BOM-managed Compose artifacts.
