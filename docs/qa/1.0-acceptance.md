# Enk 1.0 Acceptance Checklist

This document tracks the final acceptance state for the Enk 1.0 release against the product requirements in `docs/superpowers/specs/2026-11-07-enk-design.md` ("What success looks like for 1.0") and Task 28 of the 1.0 implementation plan.

Items verified via automated tests or CI gates are marked `[x]` with status `PASS`. Items requiring tactile, acoustic, or physical verification on real hardware are marked `[ ]` with status `PENDING-DEVICE` for the author's physical sign-off.

## 4. Known Gaps & Deferred Items (With Ownership)

The following items were identified during previous batch audits and are documented here with designated ownership:

1. **Physical Sound and Acoustic Latency Verification**
   - *Status:* Unverified on hardware. `SoundPoolPlayer` dispatches asynchronously; actual acoustic latency depends on device OEM audio HAL buffers.
   - *Owner:* Author (Device pass on real hardware).

2. **Physical Launcher Widget Integration**
   - *Status:* Unit tested via Glance test harness; widget appearance, resizing behavior, and interaction on OEM launchers (OneUI, Pixel Launcher, MIUI) unverified on phone.
   - *Owner:* Author (Device pass on real hardware).

3. **Compact Landscape Layout with Soft Keyboard**
   - *Status:* In extreme landscape with soft keyboard visible, paper height is constrained (~40 dp). Text survives rotation cleanly.
   - *Owner:* Author / Future UX iteration.

4. **1.12x Stretch of Pressed Bead and Fader Knobs**
   - *Status:* Graphics-layer scale transforms not measurable via Robolectric bounds assertions.
   - *Owner:* Author (Visual inspection on device).

5. **Application ID & Trademark Availability**
   - *Status:* `app.enk.notes` used as package ID; availability on Google Play / trademark registers unverified.
   - *Owner:* Author (Pre-release administrative task).

6. **Play Store Paid Features & Drive Sync**
   - *Status:* Deferred by design for 1.0 (anti-goal for F-Droid core).
   - *Owner:* Post-1.0 Roadmap (Separate closed extension module).
