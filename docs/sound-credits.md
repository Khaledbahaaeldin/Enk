# Sound credits

Draft credits for the typewriter sounds in Enk. Source pages were read on 2026-11-07. All entries below state Creative Commons 0 (CC0) on their Freesound page. CC0 does not require attribution; Enk credits the uploaders anyway, in this file, in the repository's `CREDITS` file, and on the app's About screen.

Each sample shipped in the app must also be listed in a provenance file in the repo (source URL, uploader, license, date retrieved, archived copy) because Freesound uploads can be removed. The builder fills in the cut-sample list.
