# Enk 1.0 (FOSS) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Enk 1.0, a free, open-source Android typewriter-style notes app: the approved vintage writing screen (rail, carriage, type-slug, stamp, night lamp with control panel), a glass-shell interface (Box with dividers, search, Setup, trash, widget) with five themes plus Android dynamic color, export/import, and four sound sets.

**Architecture:** Three Gradle library modules with no UI knowledge of each other: `:text` (pure Kotlin grid layout, pagination, strike model), `:design` (writer tokens and components, plus the shell: themes, glass materials, spring and gesture math, shell controls), `:audio` (sound sets and playback), plus `:data` (Room) and `:app` (screens, view models, navigation shell, widget). The writing screen is a pure function of a `WriterState` produced by a reducer, so behaviour is unit-tested without a device; the shell's physics (springs, lens, sheet, rubber band) is pure functions tested on the JVM; visuals are checked with screenshot goldens against the design system.

**Tech Stack:** Kotlin, Jetpack Compose, Material 3 1.5.x (Expressive motion; pin the exact version), Backdrop and Haze for glass (Apache-2.0), Room (FTS4), DataStore, Glance (widget), SoundPool, JUnit4, Robolectric, Paparazzi (screenshot tests), Gradle Kotlin DSL with a version catalog. Pin the latest stable versions at execution time in `gradle/libs.versions.toml`.

**Spec:** `docs/superpowers/specs/2026-11-07-enk-design.md` (product) and `docs/superpowers/specs/2026-11-07-enk-design-system.md` (every visual, motion, and sound value; referred to below as DS with section numbers).

## Global Constraints

- Native Android, Kotlin, Jetpack Compose. `minSdk = 31` for every build, F-Droid included.
- Public code under Apache-2.0. No proprietary dependency, no Google Play Services, no Firebase.
- The app must not declare the `INTERNET` permission or any other network permission. A build check enforces this (Task 1).
- Only CC0 or CC-BY assets may ship. Every bundled sample and font is listed in a provenance file with source URL, author, license (Task 12).
- Latin text only in 1.0. No RTL or CJK layout work.
- A page is about 3,000 characters; going over starts a new page and never blocks typing.
- Autocorrect is off by default. Default correction mode is clean erase.
- Trash auto-purges after 30 days. Trashed notes never appear in search or the widget.
- Four free sound sets: Classic, Antique, Soft, Keyboard. The Brother Charger 11 set is excluded until the author supplies written permission.
- Orange (`#FF5A1F`) is used only for the caret, carriage indicator strip, knob index lines, and wordmark dot. No ruler or tick marks anywhere on the rail or panel.
- Never copy Platen's artwork, capsule shape, charms, flower tabs, sounds, wording, or name.
- Placeholder application id `app.enk.notes` until the name "Enk" is verified. Package root `app.enk`.
- Visual, motion, and sound values come from the design system, verbatim. `spike-throwaway/marker-prototype-v2.html` is a reference only; never copy its code.
- Anything the design system marks PROPOSED (listed in DS 12.13: app icon artwork, credits screen layout beyond grouped rows) requires the author's approval before it is built. The writer and the shell (DS sections 1 to 12) are approved.
- Dependency injection is a hand-written container in `:app` (`AppContainer`). No Hilt or Dagger.
- Interface themes: exactly five (Graphite, Apricot, Sky, Slate, Mono) plus Dynamic (Material You, from the wallpaper), each in Light and Dark, with a Mode setting of Light, Dark, or System. Defaults: Graphite and System. Themes recolor the shell only; the writer always keeps its paper, steel, and orange (DS 12.1, 12.2).
- Glass appears only on floating chrome (nav bar, divider strip, compact bar, sheets, menus, alerts); content is opaque; never stack translucent on translucent (DS 12.1). Glass uses Backdrop (refraction on API 33 and later) with a frosted-blur fallback on API 31 and 32; Reduce effects, high-contrast text, or reduced motion switch to solid surfaces and snapped springs.
- Shell motion uses the damping-and-response spring model with the tokens in DS 12.9 (default damping 1.0; 0.8 only after a flick). Gesture-driven motion is never fixed-duration.
- Use only stable Material 3 APIs from the 1.5.x line; do not use `LoadingIndicator` or `MaterialShapes` (still experimental).
- Logo and start animation follow `docs/superpowers/specs/2026-11-07-enk-logo.md` and `2026-11-07-enk-start-animation.md`: orange only in the caret and carriage strip; the in-app animation is exactly 900 ms after the hand-off, skippable by touch, silent, and cold-start only; the system splash follows the system mode: `#ECE8DF` with ink typed lines in light mode, `#161514` with cream typed lines in dark mode.
- Every shell color pair must meet the contrast minimums in DS 12.11, checked for all ten static theme and mode combinations and a 12-hue Dynamic sweep.

## Review Focus

Inputs the spec implies but nothing else exercises; each has a test in the named task.

1. Pasting very large text (for example 200,000 characters) must paginate without freezing the UI (Task 5, Task 14).
2. Swipe typing and IME composition with autocorrect off: a composing word must commit as one insert, not stamp, strike, and duplicate characters (Task 14, Task 20).
3. The app is killed or rotated mid-sentence: no typed character is lost, because writes are debounced to at most 500 ms and flushed on pause (Task 14).
4. A corrupt, huge, or malicious import zip (path traversal like `../x`, a zip bomb, non-UTF-8 files) must fail safely with a message and no data change (Task 9).
5. Emoji and combining characters in a fixed grid: they must never crash, split a surrogate pair at a page or line break, or lose data; layout may be imperfect (Task 4, Task 5).

}
