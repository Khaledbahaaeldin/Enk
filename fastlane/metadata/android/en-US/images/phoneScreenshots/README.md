# Enk 1.0 Phone Screenshots

This directory stores the official store and promotional phone screenshots for F-Droid and repository listings.
Screenshots are captured from a real device or an Android reference emulator (e.g., Pixel 8 / 1080x2400 API 35/37) using `scripts/capture-screenshots.sh`.

## Required Screens

1. `1_day_writer.png`:
   - Day mode writing screen with active typewriter paper, several typed lines, carriage rail, and margin marker visible.
2. `2_night_writer.png`:
   - Night mode writing screen with warm desk lamp illuminated, glass control panel open, and fader levels visible.
3. `3_box.png`:
   - The Box screen showing dividers ("Unfiled", custom user dividers), note paper cards, note counts, and the glass bottom navigation bar.
4. `4_find.png`:
   - Find/Search screen with a search query, case-insensitive bold and underlined ink matches highlighted on note cards.
5. `5_setup.png`:
   - Setup screen displaying the Appearance section with a selected non-default theme (e.g. Apricot, Sky, or Slate) and shell toggle/fader controls.
